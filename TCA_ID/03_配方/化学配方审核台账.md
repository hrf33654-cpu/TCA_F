# TCA 化学配方审核台账

**基线：** 总纲 v0.4 §06～§08  
**状态：** 空台账，没有任何配方获批。总纲里的 `H₂O` 只是计量算例，不算已收录。

## 收录范围〔确认〕

前三周期主族元素，共 18 种：H、He、Li、Be、B、C、N、O、F、Ne、Na、Mg、Al、Si、P、S、Cl、Ar。

反应物只能是 `ELEMENT`；不做化合物二次合成；不模拟温度／压力；每次成功合成生成 1 张产物卡。

## 计量规则速查〔确认〕

对配方需要的每个元素 `e`：至少投入 1 张实牌，`1 ≤ C[e] ≤ Q[e]`，`S[e] = Q[e] − C[e]`，总「叠」`ΣS ≤ 当前「叠」`。不能用「叠」补出没有实牌的元素，不能超量投入。

## 两道审核

一条配方要同时通过两道审核，才能进入可执行配方池：

- **科学审核：** 物质真实存在，元素计量和反应条件有依据。
- **内容／平衡审核：** 决定是否在 TCA 开放，以及卡 ID、固定能量费用、效果、显示名、发现表现。

`合法性` 只有两个值：合法／不可用。`审核状态` 是另一个字段，枚举值还没定（待定项 X-01），下表暂时留空，不要自己编枚举。

**字段说明：**

- `元素与计量 Q`：写成 `H:2, O:1` 这种格式。
- `科学审核`：先填审核人和日期；状态枚举定下来以后再统一改。
- `合法性`：只填"合法"或"不可用"；没审过就留空，不能填"不可用"。
- `默认可见`：是否默认出现在快捷合成列表（未发现也可见）。
- 同一组元素有多个真实产物时，每个产物各占一行。
