# 氧：双眼与上半脸专项精修

基于 TASK-O12 的 104×208、单帧正面工程，使用 Aseprite MCP 直接重绘眉眼。原工程和导出图保存在 backup/；本次另存新工程。

## 本次修改

- 双眼统一高度、开合和视线，保留较窄、克制的眼型。
- 将眼线、低饱和蓝灰虹膜和最深瞳孔组织为连续小像素簇，清除原有下方游离蓝灰点。
- 降低眼白亮度；在这一尺寸下，眼白承担微小亮点功能，不另叠加纯白高光，避免拥挤和萌化。
- 梳理眉毛、上眼线间的肤色间隔，移除厚重的连续紫灰眉眼暗带。保留外侧刘海边界和蓝色挑染。
- 鼻口、脸型、发型整体和服装均保留。

新增顶层 `08_双眼重绘_窄眼型与统一视线`，可关闭比较。原八层逐像素保留。调色板、画布、帧时长与透明轮廓不变。

已检查原尺寸整体、4 倍和 8 倍头部，并在第一版后收短眼线端点、恢复刘海边界。重开保存工程，核验导出与交付 PNG 一致；verification.json 记录验证结果。
