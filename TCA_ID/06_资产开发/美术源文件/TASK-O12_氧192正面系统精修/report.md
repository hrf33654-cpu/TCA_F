## 五个可开关的修正层

1. **布料体积**：披袖与黑裙改用连贯的纵向折面，替换下摆横向量化分带，保留大块暗面，不将黑色区域整体提亮。
2. **头发与五官**：组织蓝色挑染、整理部分灰色轮廓杂点；调整眼睑、眼白、虹膜及唇线，保持克制表情，不改成Q版。
3. **胸口与宝石**：清理衬衫零碎灰点、区分侧缝与中央白布，保留纽扣和链饰；领口、胸前和手套宝石使用集中蓝色核心与细边框。
4. **白裙与花叶**：用受控薄荷折边和冷灰褶线区分荷叶边；暖白、灰米色玫瑰区别于冷白布料，叶片组织成双色簇。主要花饰、藤蔓与裙层保留。
5. **帽饰及最后校对**：整理帽子玫瑰与侧面白蝴蝶结，复核宝石高光、头发边缘与手套关节。

未镜像或交换观看方向左白右黑的礼服结构。保留原有三层及其全部像素、可见性、锁定、不透明度和混合模式；新增五层，共8层，可逐组开关比较。

## 复核结果

每组修改后观察原尺寸整体；最终检查100%、200%、400%与局部800%。剪影是一个完整连通体，没有透明区外游离像素，因此没有为清边随意删掉发梢和裙尖。画布104×208、人物范围88×192、透明轮廓逐像素保持，alpha仍仅0/255。

配色按材质功能调整，不机械限制数量：保留黑灰、冷白、薄荷及蓝色体系，增加少量暖白花瓣和宝石色票。最终43个实际实体色，调色板46项含透明；原调色板前35项保留。这里增加的颜色用于分开材质，不是全局自动减色。

最终工程重新打开，并用实际MCP和Aseprite CLI分别导出，两者与交付PNG逐像素一致。4倍和2倍预览严格匹配最近邻；对比图左旧右新，同倍率。验证与最终文件哈希：`verification/delivery-checks.json`；原图层保留核验：`verification/layer-preservation.json`。
