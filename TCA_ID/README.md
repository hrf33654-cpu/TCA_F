## 使用规则

1. 规则冲突时，以 `01_总纲` 为准。旧工作区 `E:\projects\TCA` 里的文档、代码、Unity 原型都**不是**当前规则来源。
2. 标记沿用总纲：〔确认〕〔推导〕〔待定〕〔建议〕〔目标〕。没有获批的内容不能写成〔确认〕。
3. 新决定先登记到 `04_待定项/待定项清单.md`（写明日期、影响系统、覆盖条目），再同步改总纲，并升级版本号。
4. 规则定稳之前，不在这里放 Godot 代码。旧 Godot 工程留在 `E:\projects\TCA\TCA`，暂时不动。

## 与旧工作区的关系

`E:\projects\TCA` 保留原样，作为历史参考：里面有 Unity 原型、旧 Godot 工程、两个 validation 副本和旧 docx。它的规则（比如合成扣 2 能量、每回合抽 1 张）和 v0.4 不一致。
