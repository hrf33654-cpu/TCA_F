# 景深 v4：修正上方虚化偏弱

2026-10-27，用户反馈“上方虚化明显比下方虚化弱”。本轮专门平衡上下两侧的虚实关系。

## 调整

1. 六区远景清晰余量从 8～12m 缩至 3.5～6m，远景过渡从 24～28m 缩至 10～13m。下方近景参数保持 v3 数值，避免为补上方而继续加重下方。
2. 高树冠即使在画面顶部，也可能仍处于相机的光学清晰范围。额外使用柔和的画面上沿虚化：顶端较强，向下连续衰减，默认在画面高度约 34% 处归零；缩小取景时缩至约 28%，中间和下部不受这层影响。
3. 上沿半径按分辨率补偿，720p 与 1080p 保持接近的画面比例。虚化层位于场景之上、审查文字之下，不阻挡鼠标，原版及关闭模式禁用这层。

这是本项目为上下协调采用的“光学景深＋画面上沿渐变”组合，不宣称《歧路旅人》使用了相同实现。远景和顶部的叠加会有意柔化贴近上沿的烟囱或树冠，画面中部的门口、桥面与遗迹核心仍是清晰重点。

## 证据

- `depth_profiles_v3.json` 保存修改前参数，v3 全部图像保留在上级同名目录。
- `far_pass/` 是仅调整光学远景后的六区检查图；`balanced/` 是补充上沿渐变后的六区检查图。
- `tuned/`、`legacy/`、`off/` 为最终三模式同镜头六区 720p / 1080p；`limits/` 为六区缩放、转向极限；`review_controls.png` 为审查界面。
- `validation.json` 是本版运行检查结果。检查焦点清晰、三模式、平移连续性、分辨率与转向缩放，同时检查上沿层适应窗口尺寸、不拦截输入、在原版及关闭模式隐藏，且始终位于审查界面下方。
- 本轮检查通过，失败列表为空；已查看六区前后对照、24 个极限视角总览和最终审查界面。`comparison_contact.jpg` 左列为 v3、右列为 v4，`limits_contact.jpg` 为极限视角总览；三模式、极限和界面共保存 61 张检查截图。

运行项目默认预览，按 D 切换“分区景深 / 原版景深 / 关闭景深”，1～6 查看区域；R 返回庭院，Tab 隐藏界面。重现截图与检查：有渲染的 Godot 执行 `--script res://tools/validate_depth_of_field.gd`。

上沿层使用 Godot 官方支持的屏幕纹理和 mipmap 模糊，参见 [Screen-reading shaders](https://docs.godotengine.org/en/stable/tutorials/shaders/screen-reading_shaders.html)。
